# a-whole-new-world
A procedurally generated night scene created entirely with python's Tkinter Canvas.
This program draws a stylized night sky containing stars, constellations, a moon, a flying carpet, and architectural landmarks using geometric shapes and randomly generated positions.

# Features
* Procedurally generated stars
* Randomized moon positions
* Randomized flying carpet positions
* Custom color palette
* Generated geometric illustrations
* Big Dipper and Little Dipper constellations
* Multiple architectural scenes
* Text rendered directly onto the canvas

# Built With
* Python 3
* Tkinter
* Python's random module

# How to Run
1. Make sure Python 3 is installed
2. On github, click code --> Download ZIP, and unzip the folder
3. Open a terminal and navigate to the folder containing main.py
4. Run "python main.py" or if that doesn't work, "python3 main.py"
A window should open displaying the artwork!
